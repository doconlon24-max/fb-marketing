2. Máy cài Claude Code phải đăng nhập GitHub (git đã có quyền đọc repo này).
3. Trong Claude Code:
```
/plugin marketplace add doconlon24-max/fb-marketing
/plugin install fb-marketing@fb-marketing-kho
```
4. Đọc [HUONG-DAN-CAI-DAT.md](HUONG-DAN-CAI-DAT.md) – app, kết nối, công cụ ảnh AI, chạy tự động khi tắt máy.
